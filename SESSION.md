## 2026-09-29 — Unattended optimization pass: vault-watcher crash loop + push retry (PR #5)
The chokidar vault watcher had no `'error'` listener. One unreadable vault directory (`EACCES`) crashed Node, and the watcher starts on every boot, so it became a crash loop that `restart: unless-stopped` can't fix (reproduced: the old build died within 4 s). The fix adds an error listener and wraps the add/change/unlink handlers in a `guarded()` helper. `sendPushToUser` now retries transient errors (DNS/`ECONNRESET`/429/5xx) after 5 s, 30 s and 120 s, with a 15 s send timeout and better error logs. ## 2026-09-29 — Unattended optimization pass: stop malformed auth requests crashing the server (PR #4)
The async handlers in `src/server/routes/auth.ts` had no error path, so on Express 4 a single unauthenticated request with a non-string field (e.g. `POST /api/auth/login {"email":{"a":1}}`) threw inside better-sqlite3, became an unhandled rejection, and killed Node. Six of six malformed payloads crashed the old server. An `asyncHandler` wrapper and string type checks brought that to 0/6, and a wrong password still returns 401 and a valid signup 201. Each payload was verified against a fresh prod-DB copy; stale `-wal`/`-shm` files had to be deleted between runs, or SQLite replays them. The change is on `opt/besmart-20260929-1530` as open PR #4 and is not merged or deployed. PR #3 (push timer) is now merged, and PR #2 is still open. Still open: secret rotation, `claude-maxer/` vault exclusion, compose log rotation, and the `oauthStates` map that never evicts abandoned OAuth flows.
