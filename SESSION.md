## 2026-07-31 — Investigate music pausing on tab backgrounding
User asked why music stops when switching away from the tab and only resumes on reactivation. Delegated to an Explore agent to check `MusicPlayer.tsx`, `Layout.tsx`, and `sw.js` for any visibility-change listeners, polling loops, or service-worker interference — found none: it's a plain `<audio>` element with no `MediaSession` API integration, so playback is driven entirely by browser/OS background-tab suspension (most likely on mobile Safari PWA). No code changes made; proposed adding the `MediaSession` API as the fix but the user had not yet confirmed before the session ended.

## 2026-07-28 — Fix duplicate seasonal checkin tasks
Found 25 duplicate "Seasonly" `checkin_tasks` rows for 2026-07-01: `scheduler.ts`'s seasonal/yearly task generation blocks inserted unconditionally on every hourly `scheduleJob()` run (unlike the weekly/monthly blocks, which already checked for an existing task first), so each hourly tick on a matching day created another duplicate. Added the same existing-task check to the seasonal and yearly blocks, deleted the 24 stray rows, and deployed via the `dist/` swap path (the full `docker compose build` hit a transient network timeout fetching native module headers for `better-sqlite3`, unrelated to this change).
